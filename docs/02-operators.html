01. Arithmetic Operations on Two Numbers

★ 01. Arithmetic Operations on Two Numbers.c

Program that will take two numbers X and Y as inputs, then calculate and print the values of their addition, subtraction, multiplication, division (quotient and reminder).

Sample inputSample output
 
5     10
 
Addition: 15
Subtraction: -5
Multiplication: 50
Quotient : 0
Reminder: 5
 
-5     10.5
 
Addition: 5.5
Subtraction: -15.5
Multiplication: -52.5
Quotient: 0
Reminder: -5
Solution 
// 011222131
#include <stdio.h>

int main() {
    float x, y;
    scanf("%f %f", &x, &y);

    printf("Addition: %g\n", x + y);
    printf("Subtraction: %g\n", x - y);
    printf("Multiplication: %g\n", x * y);
    printf("Quotient : %d\n", (int)x / (int)y);
    printf("Reminder: %d\n", (int)x % (int)y);
    return 0;
}

03. Evaluate Algebraic Expression

★ 03. Evaluate Algebraic Expression.c

Program that will take two numbers (a, b) as inputs and compute the value of the equation – (Without using math.h) X = (3.31 * a2 + 2.01 * b3) / (7.16 * b2 + 2.01 * a3)

Sample inputSample output
 
5            10.5
 
X = 2.315475
 
100      -250
 
X = -12.766287
Solution 
// 011222131
#include <stdio.h>

int main() {
    float a, b, x;
    scanf("%f %f", &a, &b);

    x = (3.31 * a * a + 2.01 * b * b * b) / (7.16 * b * b + 2.01 * a * a * a);

    return 0;
}

04. Increment and Decrement Operators

★★ 04. Increment and Decrement Operators.c

Program that will increment and decrement a number X by 1 inside the printf function. (Use ++ and - - operators)

Sample inputSample output
 
5
 
X++ :    5
++X :    6
X- -  :    5
--X   :    4
 
-5
 
X++ :    -5
++X :    -4
X- -  :    -5
--X   :    -6
Solution 
// 011222131
#include <stdio.h>

int main() {
    int X, x;
    scanf("%d", &X);

    x = X; printf("X++: %d\n", x++);
    x = X; printf("++X: %d\n", ++x);
    x = X; printf("X--: %d\n", x--);
    x = X; printf("--X: %d\n", --x);
    return 0;
}

07. Type Conversion and Type Casting

★★ 07. Type Conversion and Type Casting.c

Program that will declare and initialize an integer and a floating point number. Then it will perform floating to integer and integer to floating conversions using Assignment operation Type casting

Sample inputSample output
 
-150      123.125
 
Assignment:   123.125000 assigned to an int produces 123
Assignment:  -150 assigned to a float produces -150.000000
Type Casting: (float) -150 produces -150.000000
Type Casting: (int) 123.125 produces -123
Solution 
// 011222131
#include <stdio.h>

int main() {
    int i;
    float f;
    scanf("%d %f", &i, &f);

    int fromFloat = f;
    float fromInt = i;

    printf("Assignment: %f assigned to an int produces %d\n", f, fromFloat);
    printf("Assignment: %d assigned to a float produces %f\n", i, fromInt);
    printf("Type Casting: (float) %d produces %f\n", i, (float)i);
    printf("Type Casting: (int) %g produces %d\n", f, (int)f);
    return 0;
}

10. Relational and Logical NOT Operators

★★ 10. Relational and Logical NOT Operators.c

Program that will take a, b & c as inputs and decide if the statements are True (1) of False (0)

Sample inputSample output
 
10   -10   0
 
1
0
1
Solution 
// 011222131
#include <stdio.h>

int main() {
    int a, b, c;
    scanf("%d %d %d", &a, &b, &c);

    // a) (a+b) <= 80
    int resultA = (a + b <= 80) ? 1 : 0;

    // b) !(a+c)
    int resultB = !(a + c);

    // c) a != 0
    int resultC = (a != 0) ? 1 : 0;

    printf("a) %d\n", resultA);
    printf("b) %d\n", resultB);
    printf("c) %d\n", resultC);

    return 0;
}

12. Roots of a Quadratic Equation

★★★ 12. Roots of a Quadratic Equation.c

Program that will take calculate the roots of a quadratic equation (a.x2 + b.x + c = 0) from the formula, (here, dot (.) stands for multiplication) -

Sample inputSample output
 
2      4     -16
 
2.00    -4.00
 
1      2       3
 
Imaginary
Solution 
// 011222131
#include <stdio.h>
#include <math.h>

int main() {
    float a, b, c;
    scanf("%f %f %f", &a, &b, &c);

    float d = b * b - 4 * a * c;
    if (d < 0) {
        printf("Imaginary\n");
    } else {
        float r1 = (-b + sqrt(d)) / (2 * a);
        float r2 = (-b - sqrt(d)) / (2 * a);
        printf("%.2f    %.2f\n", r1, r2);
    }
    return 0;
}

13. Trigonometric Expression

★★★ 13. Trigonometric Expression.c

Program that will evaluate the equation ; where 1<= x <=180 [No checking needed]

Sample inputSample output
 
30
 
0.8927936413
 
120
 
-0.1339745962
 
180
 
3.000013
Solution 
// 011222131
#include <stdio.h>
#include <math.h>

int main() {
    int x;
    scanf("%d", &x);

    double rad = x * 3.1416 / 180.0;
    double result = 2 * pow(cos(rad), 2) - sqrt(3) * sin(rad) + sin(rad / 2);

    printf("%.10g\n", result);

    return 0;
}

14. Ceil Floor and Absolute Value

★★ 14. Ceil Floor and Absolute Value.c

Program that will take a floating point number X as input and evaluate A,B,C where- A = Value when X is rounded up to the nearest integer B = Value when X is rounded down to the nearest integer C = Absolute value of X

Sample inputSample output
 
10.6

-77.9

Solution

#include <math.h>

int main() {
    float x;
